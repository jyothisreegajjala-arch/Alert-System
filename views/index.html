Automated 60-Second Emergency Workflow

No emergency request goes unanswered with two-tier community escalation.

1

Press & Hold SOS

User holds the SOS button for 3 seconds. Live GPS location, date, time, and emergency ID are captured instantly.

2

Tier 1: Neighbors & Guards

Immediate socket broadcast to registered nearby neighbors and building security guards with live countdown timer.

3

60-Sec Escalation

If no neighbor or security accepts within 60 seconds, the server automatically escalates the alert to family & volunteers.

4

Resolution & Tracking

Responders navigate via Google Maps, assist the victim, and mark the emergency as resolved in MongoDB database.
